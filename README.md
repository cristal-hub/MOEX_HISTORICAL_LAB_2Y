# MOEX_HISTORICAL_LAB_2Y

Независимая историческая исследовательская лаборатория для MOEX.

- RESEARCH ONLY.
- NO LIVE ORDERS.
- NO REAL MONEY.
- NO BROKER EXECUTION.

## Структура

- `source_snapshot/` — снимок исходников (заполняется вручную).
- `data/raw/` — сырые данные.
- `data/normalized/` — нормализованные данные.
- `data/metadata/` — метаданные.
- `research/instruments/` — реестр инструментов.
- `research/signals/` — генераторы сигналов (A/B).
- `research/execution/` — исполнение, комиссии, slippage.
- `research/backtest/` — прогон, IS/OOS.
- `research/validation/` — статистические тесты.
- `results/trades/` — сделки.
- `results/statistics/` — метрики.
- `results/reports/` — итоговые отчёты.
- `scripts/` — вспомогательные скрипты.
- `logs/` — логи.
